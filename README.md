# Hi, I'm Fabrice

### Infrastructure & Platform Engineer | Automation and Integration

I enjoy connecting systems, solving integration problems and building tools that make infrastructure easier to operate. My work spans cloud and on-premises environments, from designing infrastructure as code to developing automation and improving deployment workflows.

I'm particularly interested in the point where infrastructure and software meet: taking an operational problem, building a solution end to end, and making it reliable and reusable for the people who use it.

## What I work on

- **Infrastructure as code:** provisioning and configuration with Terraform, OpenTofu and Ansible across cloud and virtualised environments.
- **Automation and integration:** connecting APIs and building tools and workflows with PowerShell and Python.
- **Platforms and delivery:** Kubernetes, GitOps, containers and CI/CD to make builds and deployments more consistent.
- **Operations and observability:** monitoring, troubleshooting and designing for maintainability and recovery.

## Selected projects

My homelab is a place to explore platform engineering in practice, from configuring hosts to deploying and operating applications:

- [**Home DC — Kubernetes**](https://github.com/fabricesemti80/home-dc-kubernetes) — Talos Kubernetes clusters, Argo CD GitOps, networking and infrastructure automation, with documented bootstrap and recovery workflows.
- [**Home DC — Proxmox**](https://github.com/fabricesemti80/home-dc-proxmox) — Ansible-based configuration for a standalone Proxmox host, with validation, check-mode planning and staged GPU preparation.
- [**Nix Home Machines**](https://github.com/fabricesemti80/infra-nix-home-machines) — reproducible macOS and NixOS host and user configurations using Nix flakes and Home Manager.
- [**Syncdoc Drift Demo**](https://github.com/fabricesemti80/syncdoc-drift-demo) — a small example repository for demonstrating configuration drift across Terraform, Docker and Ansible.
